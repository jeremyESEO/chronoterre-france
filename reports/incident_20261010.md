# Incident de démarrage du site — 10 octobre 2026

## Constat
La capture de production retournée par Sites pour la version 2 montre une carte vide et « Les données ne sont pas accessibles / Réponse fournisseur inattendue ». Ce message vient du contrôle du Content-Type dans getJSON, avant initMap. Les journaux Worker consultés ne contiennent pas d'erreur ; l'application est statique.

Les requêtes HTTP de diagnostic depuis cet environnement sont refusées par Cloudflare (403, code 1010), même avec le jeton de consultation fourni par Sites. L'en-tête exact des fichiers en production n'a donc pas été directement mesuré. Le refus de données à cause du type MIME est confirmé par le message ; les .geojson servis comme application/octet-stream constituent le cas reproduit.

## Reproduction et correction
Le test DOM utilisait auparavant application/json pour tous les fichiers, masquant le défaut. En servant les vrais fichiers .geojson avec application/octet-stream, le démarrage échoue avant correction (« Initialisation sans fiche »).

Le chargeur des fichiers livrés accepte maintenant les types MIME génériques et valide le corps JSON. Il refuse explicitement une page HTML (par exemple une page de connexion), le JSON mal formé et les erreurs HTTP. Les réponses de fournisseurs externes gardent leur contrat MIME strict. Les délais sont gérés par AbortController, sans dépendre de AbortSignal.timeout. Le message d'échec ne suggère plus à tort que l'utilisateur a ouvert un fichier local.

## Vérifications exécutées
- Test de régression reproduisant le défaut avant correction : échec attendu.
- tests/front_dom.cjs après correction : 8 groupes de contrôles réussis, avec vrais instantanés ; recherche, horizons, comparaison, outre-mer, panne fournisseur, fiche fossile, MIME générique, HTML et JSON invalide.
- node --check dist/app.js : réussi.

Limite : jsdom ne vérifie pas le rendu WebGL. Le contrôle interactif du navigateur n'est pas disponible dans cet environnement. La capture fournie par Sites permet de constater l'état publié, mais ne remplace pas une recette interactive.
